向量嵌入技术

学习目标： 理解向量嵌入的原理、主流嵌入模型的选择，以及如何在RAG系统中应用向量嵌入。

什么是向量嵌入？

向量嵌入（Vector Embedding）是将文本转换为高维向量空间中的点的过程。核心思想是：语义相似的文本在向量空间中距离更近。

例如：

  • "如何退款" 和 "退货流程" 字面上几乎不重合，但在向量空间中距离很近
  • "Python编程" 和 "Java开发" 在向量空间中距离较近
  • "Python编程" 和 "烹饪食谱" 在向量空间中距离很远

向量嵌入的工作原理

1. 嵌入模型

嵌入模型是专门用于将文本转换为向量的神经网络。常见的嵌入模型包括：

  • OpenAI Embeddings： text-embedding-3-small, text-embedding-3-large
  • Hugging Face模型： BAAI/bge-large-zh-v1.5, sentence-transformers/all-MiniLM-L6-v2
  • 本地模型： 通过Ollama等工具运行的本地嵌入模型

2. 向量空间

嵌入模型将文本转换为固定长度的向量（如768维或1536维）。这个向量空间具有以下特性：

  • 语义相似性： 语义相似的文本在向量空间中距离更近
  • 线性关系： 向量之间可以进行数学运算，捕捉语义关系
  • 聚类特性： 相似主题的文本会聚集在一起

3. 相似度计算

在RAG系统中，常用的相似度计算方法有三种：

3.1 余弦相似度（Cosine Similarity）

计算两个向量之间的夹角余弦值，最常用的相似度度量：

# 余弦相似度公式
similarity = (A · B) / (||A|| * ||B||)

# 其中：
# A 和 B 是两个向量
# A · B 是向量点积
# ||A|| 和 ||B|| 是向量的模长

# 值范围：[-1, 1]
# 1 表示完全相同，0 表示无关，-1 表示完全相反

3.2 欧氏距离（Euclidean Distance）

计算两个向量在空间中的直线距离，距离越小表示越相似：

# 欧氏距离公式
distance = sqrt(Σ(Ai - Bi)²)

# 其中：
# A 和 B 是两个向量
# Ai 和 Bi 是向量的第i个维度

# 值范围：[0, +∞)
# 距离越小，相似度越高

3.3 点积（Dot Product）

计算两个向量的点积，需要向量已经归一化（模长为1）：

# 点积公式
similarity = Σ(Ai × Bi)

# 当向量已归一化时，点积等价于余弦相似度
# 值范围：(-∞, +∞)
# 值越大，相似度越高
方法选择建议：
  • 余弦相似度： 最常用，对向量模长不敏感，适合大多数场景
  • 欧式距离： 对向量模长敏感，适合需要考虑向量长度的场景
  • 点积： 计算效率高，适合向量已归一化的场景

向量数据库

向量数据库是专门用于存储和检索向量的数据库。向量数据库的核心特点是：

重要概念： 向量数据库中存储的不是单纯的向量，而是文本+向量的组合。这样在检索时既能找到相似的向量，又能获取对应的原始文本内容。

向量数据库存储结构：

# 向量数据库中的每条记录包含：
{
    "id": "doc_chunk_001",           # 唯一标识符
    "text": "如何申请退款...",        # 原始文本内容
    "embedding": [0.1, 0.2, ...],   # 向量嵌入
    "metadata": {                   # 元数据
        "source": "help_center",
        "category": "refund",
        "created_at": "2026-01-15"
    }
}

1. ChromaDB

轻量级、易于使用的向量数据库，适合快速原型开发。

# ChromaDB示例代码
from langchain_community.vectorstores import Chroma
from langchain_community.embeddings import HuggingFaceEmbeddings

# 初始化嵌入模型
embeddings = HuggingFaceEmbeddings(model_name="BAAI/bge-large-zh-v1.5")

# 创建向量数据库
vectorstore = Chroma.from_documents(
    documents=chunks,
    embedding=embeddings,
    persist_directory="./chroma_db"
)

# 检索相似文档
results = vectorstore.similarity_search("如何退款", k=3)

2. Pinecone

全托管的向量数据库服务，适合生产环境。

3. Milvus

开源的分布式向量数据库，适合大规模数据。

4. FAISS

Facebook开源的向量检索库，适合高性能检索。

在InterviewMentorAI中的应用

项目特定考虑：
  • 中文优化： 选择对中文支持好的嵌入模型，如BAAI/bge-large-zh-v1.5
  • 本地部署： 考虑隐私和成本，使用本地嵌入模型
  • 混合检索： 结合向量检索和关键词检索，提高检索效果
  • 实时更新： 支持知识库的动态更新和增量索引

推荐技术栈

  1. 嵌入模型： BAAI/bge-large-zh-v1.5（中文优化，本地部署）
  2. 向量数据库： ChromaDB（轻量级，易于集成）
  3. 检索策略： 混合检索（向量检索 + BM25关键词检索）
  4. 重排序： 使用交叉编码器对检索结果进行重排序
