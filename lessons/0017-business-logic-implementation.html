业务逻辑实现（核心模块串联）

学习目标： 理解 InterviewMentorAI 完整的面试分析流程，掌握各 Service 模块如何协同工作，学会从面试创建到报告生成的完整链路实现。

核心业务流程：一次完整的面试

想象一下你是一名 HR，要组织一场面试。整个流程就像一条流水线：

1. HR 创建面试会话（预约面试）
   POST /session/create { title: "产品经理终面" }
   ↓ 返回 { sessionId, inviteCode: "A1B2C3" }
   
2. HR 将邀请码发给候选人（发邀请函）

3. 候选人使用邀请码加入面试（到场签到）
   GET /session/code/{inviteCode}
   ↓ 返回 { sessionId, title, is_valid: true }
   
4. 候选人录制并上传音频（开始面试）
   POST /interview/{id}/audio (FormData: audio.wav)
   ↓
   Java 后端:
     1. 保存音频文件到 MinIO
     2. 创建面试记录
     3. 异步调用 Python AI 后端
     4. 立即返回 { interviewId, status: "uploaded" }
   
5. Python AI 分析中...（面试官记录笔记）
   Java 通过 STOMP 推送进度
   Flutter 显示 "分析中..." 动画
   
6. Python 分析完成，返回结果（面试结束）
   {
     "evaluations": [
       { "dimension": "沟通能力", "score": 85, "summary": "表达清晰..." },
       { "dimension": "专业能力", "score": 78, "summary": "基础知识扎实..." }
     ]
   }
   
7. Java 保存评估结果到数据库（整理面试记录）

8. Java 生成综合报告（出面试报告）
   计算加权总分，生成建议
   
9. Java 通过 STOMP 推送最终结果给 Flutter（发送报告）

10. HR 查看报告，可选择人工修正（审核报告）
    PUT /report/evaluation/{id}/correct
    
11. 系统自动更新最终分数（定稿）

核心服务实现

InterviewService（面试服务）

InterviewService 就像面试的"总协调人"，负责整个面试流程的管理。

@Service
public class InterviewServiceImpl implements InterviewService {
    
    private final InterviewRecordMapper interviewMapper;
    private final InterviewSessionMapper sessionMapper;
    private final WsPushService wsPushService;
    private final PythonAiClient pythonAiClient;
    
    @Override
    public InterviewRecord createInterview(CreateInterviewRequest request, Long currentUserId) {
        Long tenantId = TenantContext.getTenantId();
        
        InterviewRecord record = new InterviewRecord();
        record.setTenantId(tenantId);
        record.setUserId(request.getUserId() != null ? request.getUserId() : currentUserId);
        record.setTitle(request.getTitle());
        record.setStatus("CREATED");
        record.setCreatedAt(LocalDateTime.now());
        
        interviewMapper.insert(record);
        
        // 推送面试创建成功
        wsPushService.pushInterviewCreated(tenantId, record.getId(), currentUserId);
        
        return record;
    }
    
    @Async("aiAnalysisExecutor")
    @Override
    public void uploadAudioAndAnalyze(Long interviewId, MultipartFile file, Long currentUserId) {
        Long tenantId = TenantContext.getTenantId();
        
        try {
            // 1. 上传音频到 MinIO
            String audioFileId = uploadToMinio(file);
            
            // 2. 更新面试记录
            InterviewRecord record = interviewMapper.selectById(interviewId);
            record.setAudioFileId(audioFileId);
            record.setStatus("UPLOADED");
            interviewMapper.updateById(record);
            
            // 3. 推送音频上传成功
            wsPushService.pushAudioUploaded(tenantId, interviewId, currentUserId);
            
            // 4. 调用 Python AI 后端
            wsPushService.pushAnalysisStatus(tenantId, interviewId, "analyzing");
            
            Map<String, Object> aiResult = pythonAiClient.analyzeAudio(audioFileId, "wav");
            
            // 5. 解析并保存评估结果
            List<Evaluation> evaluations = parseEvaluations(aiResult, interviewId);
            for (Evaluation eval : evaluations) {
                evaluationMapper.insert(eval);
            }
            
            // 6. 生成综合报告
            Report report = generateReport(interviewId, evaluations);
            reportMapper.insert(report);
            
            // 7. 推送分析完成
            record.setStatus("COMPLETED");
            interviewMapper.updateById(record);
            
            wsPushService.pushAnalysisComplete(tenantId, interviewId, evaluations.get(0));
            
        } catch (Exception e) {
            log.error("音频分析失败", e);
            wsPushService.pushAnalysisError(tenantId, interviewId, e.getMessage());
        }
    }
    
    private Report generateReport(Long interviewId, List<Evaluation> evaluations) {
        // 计算加权总分
        int totalScore = evaluations.stream()
                .mapToInt(Evaluation::getAiScore)
                .sum() / evaluations.size();
        
        // 生成综合建议
        String recommendation = totalScore >= 80 ? "强烈推荐" :
                               totalScore >= 60 ? "推荐" : "待定";
        
        Report report = new Report();
        report.setInterviewId(interviewId);
        report.setTotalScore(totalScore);
        report.setSummary("综合评估报告...");
        report.setRecommendation(recommendation);
        report.setCreatedAt(LocalDateTime.now());
        
        return report;
    }
}

InterviewSessionService（面试会话服务）

InterviewSessionService 就像面试的"前台接待"，负责面试会话的创建和邀请码管理。

@Service
public class InterviewSessionServiceImpl implements InterviewSessionService {
    
    private final InterviewSessionMapper sessionMapper;
    
    @Override
    public Map<String, Object> createSession(Long userId, String title) {
        Long tenantId = TenantContext.getTenantId();
        
        // 生成6位邀请码
        String inviteCode = generateInviteCode();
        
        InterviewSession session = new InterviewSession();
        session.setTenantId(tenantId);
        session.setCreatedBy(userId);
        session.setTitle(title);
        session.setInviteCode(inviteCode);
        session.setStatus("WAITING");
        session.setCreatedAt(LocalDateTime.now());
        
        sessionMapper.insert(session);
        
        return Map.of(
            "sessionId", session.getId(),
            "inviteCode", inviteCode,
            "title", title
        );
    }
    
    private String generateInviteCode() {
        // 生成6位大写字母和数字
        String chars = "ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789";
        Random random = new Random();
        StringBuilder code = new StringBuilder();
        for (int i = 0; i < 6; i++) {
            code.append(chars.charAt(random.nextInt(chars.length())));
        }
        return code.toString();
    }
    
    @Override
    public Map<String, Object> getSessionByCode(String inviteCode) {
        InterviewSession session = sessionMapper.selectByInviteCode(inviteCode);
        
        if (session == null) {
            throw new BusinessException("邀请码无效");
        }
        
        // 检查邀请码是否有效（24小时内）
        long hoursSinceCreation = ChronoUnit.HOURS.between(
            session.getCreatedAt(), LocalDateTime.now());
        if (hoursSinceCreation > 24) {
            throw new BusinessException("邀请码已过期");
        }
        
        return Map.of(
            "sessionId", session.getId(),
            "title", session.getTitle(),
            "is_valid", true
        );
    }
}

ReportService（报告服务）

ReportService 就像面试的"档案管理员"，负责报告的查看和人工修正。

@Service
public class ReportServiceImpl implements ReportService {
    
    private final EvaluationMapper evaluationMapper;
    private final ReportMapper reportMapper;
    private final WsPushService wsPushService;
    
    @Override
    public List<Evaluation> getEvaluations(Long interviewId) {
        return evaluationMapper.selectByInterviewId(interviewId);
    }
    
    @Override
    public void correctEvaluation(Long evaluationId, HrCorrectionRequest request) {
        Evaluation evaluation = evaluationMapper.selectById(evaluationId);
        if (evaluation == null) {
            throw new BusinessException("评估记录不存在");
        }
        
        // HR 人工修正
        evaluation.setHrScore(request.getHrScore());
        evaluation.setHrRemark(request.getHrRemark());
        
        // 使用人工修正后的分数
        evaluation.setFinalScore(request.getHrScore());
        evaluation.setFinalSummary(request.getHrRemark());
        
        evaluationMapper.updateById(evaluation);
        
        // 推送修正结果
        Long tenantId = TenantContext.getTenantId();
        wsPushService.pushEvaluationCorrected(tenantId, evaluation.getInterviewId(), evaluation);
    }
    
    @Override
    public Report getReport(Long interviewId) {
        return reportMapper.selectByInterviewId(interviewId);
    }
}

数据流说明：
  1. Flutter 通过 HTTP 请求与 Java 后端通信
  2. Java 后端通过 RestClient 调用 Python AI 后端
  3. Python AI 后端通过 JDBC 查询 MySQL 数据库
  4. Java 后端通过 STOMP 推送实时消息给 Flutter

Service 层设计原则

单一职责：每个 Service 只做一件事

Service 职责 类比
InterviewService 面试的创建、上传、分析触发 面试总协调人
InterviewSessionService 面试会话和邀请码管理 前台接待
ReportService 报告查看和人工修正 档案管理员
SubscriptionService 订阅额度管理 财务人员

依赖注入：使用构造器注入

@Service

    }
}

事务管理：保证数据一致性

@Override
@Transactional  // 事务注解
public void correctEvaluation(Long evaluationId, HrCorrectionRequest request) {
    // 数据库操作在同一事务中
    Evaluation evaluation = evaluationMapper.selectById(evaluationId);
    evaluation.setHrScore(request.getHrScore());
    evaluationMapper.updateById(evaluation);
    
    // 如果抛出异常，整个事务回滚
}
事务注意： @Transactional 只对数据库操作有效。如果方法中调用了外部服务（如 REST API），这些调用不会被事务管理。需要考虑分布式事务或最终一致性方案。
