RAG系统评估

学习目标： 掌握RAG系统的评估方法，理解如何度量检索质量和生成质量，以及如何在InterviewMentorAI项目中应用评估。

为什么需要评估？

RAG系统的效果不能只看最终回答，需要分环节评估。检索质量决定了系统的上限，生成质量决定了系统的下限。

关键原则： 数据和评测比模型调优重要。大多数RAG项目翻车都输在数据质量和评估不足上。

评估维度

1. 检索质量评估

评估检索器能否找到相关文档。

指标 定义 计算公式
召回率（Recall） 相关文档被检索到的比例 召回率 = 检索到的相关文档数 / 所有相关文档数
精确率（Precision） 检索到的文档中相关文档的比例 精确率 = 检索到的相关文档数 / 检索到的文档总数
F1分数 召回率和精确率的调和平均 F1 = 2 × (精确率 × 召回率) / (精确率 + 召回率)
MRR（Mean Reciprocal Rank） 第一个相关文档排名的倒数 MRR = 1/Q × Σ(1/rank_i)

2. 生成质量评估

评估生成器能否基于检索到的上下文生成准确回答。

指标 定义 评估方法
忠实度（Faithfulness） 回答是否基于检索到的上下文 人工评估或LLM评估
相关性（Relevance） 回答是否与问题相关 人工评估或LLM评估
完整性（Completeness） 回答是否完整覆盖问题 人工评估或LLM评估
幻觉率（Hallucination Rate） 回答中编造信息的比例 人工评估或LLM评估

3. 端到端评估

评估整个RAG系统的效果。

  • 准确率（Accuracy）： 最终回答是否正确
  • 延迟（Latency）： 系统响应时间
  • 成本（Cost）： API调用和存储成本
  • 用户满意度： 用户对回答的满意度评分

评估工具

1. RAGAS

RAGAS（Retrieval Augmented Generation Assessment）是一个专门用于评估RAG系统的框架。

# RAGAS评估示例
from ragas import evaluate
from ragas.metrics import (
    faithfulness,
    answer_relevancy,
    context_precision,
    context_recall,
)

# 准备评估数据
eval_dataset = {
    "question": ["如何退款？"],
    "answer": ["您可以在7天内申请退款..."],
    "contexts": [["退款政策：7天内无理由退款..."]],
    "ground_truth": ["7天内无理由退款"]
}

# 执行评估
result = evaluate(
    dataset=eval_dataset,
    metrics=[
        faithfulness,
        answer_relevancy,
        context_precision,
        context_recall,
    ],
)

print(result)

2. LangSmith

LangSmith是LangChain的可观测性平台，可以追踪和分析RAG系统的性能。

3. 自定义评估

根据项目需求，可以构建自定义的评估指标。

在InterviewMentorAI中的应用

项目特定评估维度：
  • 对话连贯性： 检索到的对话片段是否保持连贯
  • 评估准确性： 生成的评估是否准确反映应聘者表现
  • 引用准确性： 评估报告是否正确引用对话内容
  • 实时性： 系统响应时间是否满足实时需求

评估流程

  1. 数据准备： 收集真实的面试对话和评估结果
  2. 基准测试： 建立评估基准，定义成功标准
  3. 持续监控： 在生产环境中持续监控系统性能
  4. 反馈循环： 根据评估结果优化系统
