知识体系回顾

1. SaaS 多租户架构

概念 说明 类比
隔离策略 共享数据库 + 独立 Schema 同一栋楼，不同公司租不同楼层
租户上下文 ThreadLocal 存储当前租户 ID 每个员工的工作证（知道自己属于哪家公司）
数据隔离 所有查询自动添加 tenantId 条件 每份文件都贴有公司标签

2. Spring Boot 3 + Java 17

概念 说明 类比
分层架构 Controller → Service → Mapper → Entity 餐厅的组织结构：前厅 → 厨房 → 采购 → 食材
依赖注入 构造器注入优于字段注入 新员工入职时领取工作用品（而不是自己去找）
配置管理 application.yml 统一配置 公司的规章制度手册

3. 安全认证

概念 说明 类比
JWT 双 Token accessToken（2小时）+ refreshToken（7天） 门禁卡（短期）+ 员工证（长期）
RBAC 三级角色 平台管理员 → 租户管理员 → 租户成员 董事长 → 部门经理 → 普通员工
权限控制 @PreAuthorize 注解实现方法级权限 不同级别员工能进入不同区域

4. 异步与实时通信

概念 说明 类比
异步处理 @Async + ThreadPoolTaskExecutor 拿取餐器等餐（不用站在柜台等）
WebSocket STOMP 协议 + SockJS 降级 对讲机系统（实时通信）
实时推送 SimpMessagingTemplate 广播 广播通知（所有人同时收到）

5. API 设计

概念 说明 类比
RESTful 资源导向，HTTP 方法表示操作 餐厅菜单（菜品 = 资源，点菜 = 操作）
统一响应 Result<T> 包装类 统一格式的账单
异常处理 GlobalExceptionHandler 全局处理 万能服务员（处理各种问题）

常见问题解答

Q1: 如何处理跨租户的用户登录？

A: 用户登录时需要指定租户。可以通过以下方式：
   1. URL 参数：/auth/login?tenantId=1
   2. 下拉框选择：用户在登录页面选择所属租户
   3. 域名解析：通过子域名自动识别租户（tenant1.example.com）
   
   示例实现：
   @PostMapping("/login")
   public Result<Map<String, Object>> login(
           @RequestBody LoginRequest request) {
       User user = userMapper.selectByUsernameAndTenantId(
           request.getUsername(), request.getTenantId());
       // ...
   }

Q2: 如何处理 Python 后端调用失败？

A: 使用重试机制和降级策略：
   
   @Async("aiAnalysisExecutor")
   public void analyzeWithRetry(Long interviewId, String audioFileId) {
       int maxRetries = 3;
       for (int i = 0; i < maxRetries; i++) {
           try {
               pythonAiClient.analyzeAudio(audioFileId, "wav");
               return;
           } catch (Exception e) {
               log.warn("第 {} 次调用失败", i + 1, e);
               if (i == maxRetries - 1) {
                   wsPushService.pushAnalysisError(...);
               }
               Thread.sleep(1000 * (i + 1)); // 指数退避
           }
       }
   }
