InterviewMentorAI集成

学习目标： 掌握如何将RAG技术集成到InterviewMentorAI项目中，理解项目特定的架构设计和实现策略。

项目现状分析

根据对InterviewMentorAI代码库的分析，当前项目存在以下特点：

  • 纯LLM推理模式： 当前AI分析流程完全依赖LLM，没有外部知识库支持
  • 双后端架构： Java业务后端 + Python AI后端，职责清晰
  • 实时通信： 支持WebSocket实时推送AI处理进度
  • 数据存储： H2内存/文件数据库，适合原型开发
集成挑战：
  • 需要在不破坏现有架构的前提下添加RAG功能
  • 需要考虑中文面试场景的特殊需求
  • 需要支持实时性和准确性的平衡
  • 需要与现有的LLM服务（千问/DeepSeek）集成

RAG集成架构设计

1. 数据流重构

在现有数据流中添加RAG组件：

# 现有数据流
Flutter (录音) → Java后端 (音频管理) → Python后端 (LLM分析) → 报告生成

# 添加RAG后的数据流
Flutter (录音) → Java后端 (音频管理) → Python后端 (RAG增强分析) → 报告生成
                                      ↑
                                      知识库检索
                                      (面试知识库)

2. 组件设计

需要添加以下RAG组件：

  1. 知识库管理模块： 负责面试知识的存储和管理
  2. 检索服务： 负责从知识库中检索相关信息
  3. 嵌入服务： 负责文本向量化
  4. 向量数据库： 负责存储和检索向量

实现步骤

第二步：数据预处理

对知识库进行预处理，包括：

# 数据预处理流程
1. 文档清洗：去除无关内容，统一格式
2. 文档分块：按语义或结构进行分块
3. 元数据提取：提取标题、分类、难度等元数据
4. 向量嵌入：使用嵌入模型生成向量
5. 索引构建：在向量数据库中建立索引

第三步：检索服务开发

开发检索服务，支持多种检索策略：

# 检索服务接口设计
class RetrievalService:
    def __init__(self, vector_store, bm25_index):
        self.vector_store = vector_store
        self.bm25_index = bm25_index
    
    def hybrid_retrieval(self, query, k=5):
        """混合检索：结合向量检索和BM25"""
        # 向量检索
        vector_results = self.vector_store.similarity_search(query, k=k)
        
        # BM25检索
        bm25_results = self.bm25_index.search(query, k=k)
        
        # 融合结果
        return self.merge_results(vector_results, bm25_results)
    
    def context_aware_retrieval(self, query, dialogue_context):
        """上下文感知检索：考虑对话上下文"""
        # 分析对话上下文，生成增强查询
        enhanced_query = self.enhance_query_with_context(query, dialogue_context)
        
        # 执行检索
        return self.hybrid_retrieval(enhanced_query)

第四步：LLM服务增强

增强现有的LLM服务，支持RAG功能：

# LLM服务增强
class EnhancedLLMService:
    def __init__(self, retrieval_service, llm_client):
        self.retrieval_service = retrieval_service
        self.llm_client = llm_client
    
    def rag_enhanced_evaluation(self, question, answer, context):
        """RAG增强的评估"""
        # 1. 检索相关知识
        relevant_knowledge = self.retrieval_service.context_aware_retrieval(
            f"评估问题：{question}，回答：{answer}",
            context
        )
        
        # 2. 构建增强提示
        enhanced_prompt = self.build_rag_prompt(
            question, answer, relevant_knowledge
        )
        
        # 3. 调用LLM进行评估
        return self.llm_client.evaluate(enhanced_prompt)

技术选型建议

组件 推荐方案 理由
