# Java技术难点标准答案

## 1. Java集合框架

### HashMap底层原理

**标准答案要点：**
- 基于数组+链表+红黑树（JDK1.8+）
- 默认容量16，负载因子0.75
- put流程：计算hash → 定位桶 → 插入/更新
- 扩容机制：容量翻倍，重新hash分布
- 线程不安全，多线程使用ConcurrentHashMap

**优秀回答应包含：**
- hash扰动函数的作用
- 链表转红黑树的阈值（8）
- 红黑树退化为链表的阈值（6）
- 序列化对hash的影响

### ConcurrentHashMap原理

**标准答案要点：**
- JDK1.7：分段锁（Segment）
- JDK1.8：CAS + synchronized
- Node数组 + 链表/红黑树
- size()使用baseCount + CounterCell

**优秀回答应包含：**
- 为什么放弃分段锁
- synchronized锁升级过程
- 与Hashtable的对比

### ArrayList vs LinkedList

**标准答案要点：**
- ArrayList：动态数组，随机访问O(1)，插入删除O(n)
- LinkedList：双向链表，随机访问O(n)，插入删除O(1)
- 内存占用：LinkedList每个节点额外指针开销

**优秀回答应包含：**
- ArrayList扩容策略（1.5倍）
- LinkedList实现Deque接口
- 实际场景选择建议

## 2. JVM内存模型

### JVM内存区域

**标准答案要点：**
- 堆（Heap）：对象实例，GC主要区域
- 方法区（Metaspace）：类信息、常量池
- 虚拟机栈：方法调用、局部变量
- 本地方法栈：Native方法
- 程序计数器：当前线程执行位置

**优秀回答应包含：**
- 各区域线程共享/私有属性
- JDK8移除永久代的原因
- 堆的分代结构（新生代、老年代）

### 垃圾回收机制

**标准答案要点：**
- 可达性分析：GC Roots引用链
- 回收算法：标记-清除、复制、标记-整理
- 分代收集：新生代用复制算法，老年代用标记-整理
- 常见GC器：Serial、Parallel、CMS、G1

**优秀回答应包含：**
- GC Roots的种类
- 三色标记法
- G1的Region划分
- ZGC的染色指针

### 类加载机制

**标准答案要点：**
- 加载 → 验证 → 准备 → 解析 → 初始化
- 双亲委派模型
- 打破双亲委派：SPI、OSGi、Tomcat

**优秀回答应包含：**
- 各阶段的具体工作
- 为什么需要双亲委派
- 线程上下文类加载器

## 3. 多线程与并发

### synchronized原理

**标准答案要点：**
- 对象头Mark Word存储锁信息
- 锁升级：无锁 → 偏向锁 → 轻量级锁 → 重量级锁
- 底层实现：monitorenter/monitorexit

**优秀回答应包含：**
- 偏向锁的撤销条件
- 自旋锁的适用场景
- 锁消除和锁粗化

### volatile关键字

**标准答案要点：**
- 可见性：立即刷新到主内存
- 有序性：禁止指令重排
- 不保证原子性

**优秀回答应包含：**
- 内存屏障实现
- DCL单例为什么需要volatile
- volatile vs synchronized对比

### 线程池原理

**标准答案要点：**
- 核心参数：corePoolSize、maximumPoolSize、keepAliveTime
- 执行流程：核心线程 → 队列 → 非核心线程 → 拒绝策略
- 常见线程池：FixedThreadPool、CachedThreadPool、ScheduledThreadPool

**优秀回答应包含：**
- 为什么不推荐Executors创建线程池
- 拒绝策略的选择
- 线程池监控方法

## 4. Spring框架

### Spring IOC原理

**标准答案要点：**

- 循环依赖解决（三级缓存）
- AOP代理创建时机
- @Autowired注入原理

### Spring AOP原理

**标准答案要点：**
- 面向切面编程：横切关注点分离
- 两种代理：JDK动态代理、CGLIB
- 核心概念：切面、连接点、通知、切入点

**优秀回答应包含：**
- JDK代理 vs CGLIB选择
- 通知执行顺序
- @Transactional失效场景

### Spring Boot自动配置

**标准答案要点：**

- @Conditional条件注解

**优秀回答应包含：**
- 自动配置原理流程
- 自定义Starter步骤
- 配置文件优先级

## 5. MySQL数据库

**标准答案要点：**

- 聚簇索引 vs 非聚簇索引
- 索引类型：主键索引、唯一索引、联合索引

**优秀回答应包含：**

**优秀回答应包含：**

- 间隙锁作用
- 如何选择隔离级别
