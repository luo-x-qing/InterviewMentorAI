方案 5：优化 BM25 实现

Q1：中文分词方案？

A：jieba 精确模式（jieba.lcut）— 选中
B：pkuseg / HanLP
理由：jieba 轻量成熟，满足中文面试场景分词需求，启动快无需下载模型。

Q2：IDF 预计算策略？

A：懒加载（_idf_dirty 标志 + _ensure_idf_ready）— 选中
B：每次搜索实时计算
理由：知识库入库是离线批量操作，搜索时才需要 IDF。懒加载避免批量插入时重复重建。

Q3：IDF 公式？

A：log((N - df + 0.5) / (df + 0.5) + 1.0) — 选中
B：log(N / df)
理由：BM25 官方变体，平滑处理罕见词，避免 IDF 为负。

Q4：混合检索 BM25 归一化？

A：动态除以当前批次最大 BM25 分数 — 选中
B：保留硬编码 /10
理由：BM25 分数无上界，硬编码 /10 依赖经验值；动态归一化自适应不同查询。

Q5：IDF 重建时机？

A：insert_chunk 后标记脏，搜索前自动重建 — 选中
B：每次 insert_chunk 后立即重建

分词 & BM25 前后对比

Before（正则分词 + IDF 占位符）
_tokenize：re.findall(r'[\u4e00-\u9fff]+|[a-zA-Z]+|\d+', text)
→ "我今天去ABC公司面试"
→ ['我今', '天去', '公司', '面试']（字符粘连）
_bm25_score：idf = 1.0（占位符）
→ 所有词权重相等，稀有词无区分度
search_hybrid：bm25_norm = score / 10（硬编码）
→ 不同查询结果分数范围不一致
After（jieba 分词 + 真实 IDF）
_tokenize：jieba.lcut(text) → 转为小写
→ "我今天去ABC公司面试"
→ ['我', '今天', '去', 'abc', '公司', '面试']（语义分词）
_bm25_score：idf = _idf_cache.get(token, 1.0)
→ 稀有词得分更高，区分度显著
search_hybrid：bm25_norm = score / max_batch
→ 自适应归一化
