# backend_python（RAG 知识库上下文）

Python AI 后端的 RAG 上下文：管理题库文档从拖入到入库的完整生命周期，并为面试评估提供检索增强参考。

## Language

**题库 (Question Bank)**:
一份入库的题库文档（MD/TXT/PDF 等，转换后统一为 MD）。是入库、更新、删除的基本管理单元。
_Avoid_: 文档（太泛）、文件

**题目 (Question)**:
题库中一道完整的问题，含问题、标准答案、评估要点及溯源元数据。入库、检索、评估的一等概念；检索命中即返回完整题目。
_Avoid_: 分块、片段、chunk

**参考上下文 (Reference Context)**:
检索命中的题目拼装后提供给 LLM 评估的知识库参考文本。
_Avoid_: 上下文、RAG 结果

**入库管道 (Ingest Pipeline)**:
把题库从「拖入」加工到「可检索」的单入口深度模块，编排清洗→解析→切面→向量化→落库→自检。
_Avoid_: 导入服务、入库流程

**入库报告 (Import Report)**:
入库管道每次执行的产物，记录识别题目数、分块数、向量数、去重数、失败项与自检结论。
_Avoid_: 导入结果、日志

**清洗 (Cleaning)**:
入库管道第一步：去噪、规范化、内容指纹去重。
_Avoid_: 预处理

**结构化切面 (Structured Chunking)**:
以题目为粒度切分，保留题目编号与来源；超长答案按句/段边界二次切分。
_Avoid_: 分块、切分

**指纹 (Fingerprint)**:
题目/文件的哈希标识，用于幂等去重与变更检测。
_Avoid_: hash（实现细节）

**对账 (Reconciliation)**:
入库管道对文件指纹与目录清单的比对，删除已消失文件的旧分块，保证库与源一致。
_Avoid_: 同步

**自检 (Self-check)**:
入库后的自动验证：stats 对账 + 抽样检索自测，失败则回滚该文件。
_Avoid_: 验证、检查

## Agentic RAG

**Agentic 答案合成 (Agentic Answer)**:
对一个问题，经 LangGraph 工作流（检索→扩展→评估→必要时重查→合成）产出的一组完整题目候选（含同一题全部块拼接的完整答案与相关性标记），解决单块检索的答案截断与无关候选问题。
_Avoid_: agent 答案、多步检索

**答案候选 (Answer Candidate)**:
Agentic 合成结果中的一道完整题目：来源、题号、组内最高相似度、全部块拼接的完整答案、相关性标记（related）。
_Avoid_: chunk、命中块

**扩展 (Expand)**:
Agentic 工作流节点：按（来源, 题号）拉取同一题的全部块并拼接成完整答案（去相邻块重叠），弥补检索只命中超长题目首块的截断。
_Avoid_: 拼块、块合并

**评估 (Assess)**:
Agentic 工作流节点：离线规则判定候选相关性（相似度阈值 + 关键词重合），全不相关时触发二次检索。
_Avoid_: 打分、judge
