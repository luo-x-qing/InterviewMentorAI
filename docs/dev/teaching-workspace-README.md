# InterviewMentorAI教学工作区

本工作区是InterviewMentorAI项目的RAG技术学习中心，提供系统化的RAG技术学习路径。

## 目录结构

```
InterviewMentorAI/
├── MISSION.md                    # 学习目标
├── RESOURCES.md                  # 学习资源
├── NOTES.md                      # 学习笔记
├── assets/                       # 共享资源
│   └── styles.css               # 共享样式表
├── lessons/                      # 课程目录
│   ├── 0001-rag-core-concepts.html
│   ├── 0002-document-chunking.html
│   ├── 0003-vector-embeddings.html
│   ├── 0004-retrieval-strategies.html
│   ├── 0005-rag-evaluation.html
│   ├── 0006-interview-mentor-integration.html
│   ├── 0007-implementation-guide.html
│   ├── 0008-optimization-extension.html
│   └── 0009-summary-next-steps.html
└── docs/learning/records/        # 学习记录
    └── 0001-rag-learning-start.md
```

## 学习路径

### 第一阶段：RAG基础概念
1. **RAG核心概念** - 理解RAG的基本原理和工作流程
2. **文档分块策略** - 掌握文档分块的方法和最佳实践
3. **向量嵌入技术** - 学习向量嵌入的原理和主流模型

### 第二阶段：RAG技术深入
4. **检索策略与优化** - 掌握各种检索策略和优化方法
5. **RAG系统评估** - 学习如何评估RAG系统的效果

### 第三阶段：项目集成
6. **InterviewMentorAI集成** - 了解如何将RAG集成到项目中
7. **实现指南** - 具体的实现步骤和代码示例

### 第四阶段：高级优化
8. **优化与扩展** - 学习高级RAG模式和优化方法
9. **总结与下一步** - 总结学习成果，提供进一步学习建议

## 如何使用

### 开始学习
1. 阅读 `MISSION.md` 了解学习目标
2. 查看 `RESOURCES.md` 获取学习资源
3. 按顺序学习课程，每个课程包含：
   - 学习目标
   - 核心概念讲解
   - 代码示例
   - 实践练习
   - 下一步学习建议

### 学习建议
- **理论与实践结合**：每个课程都有代码示例，建议边学边实践
- **循序渐进**：按照课程顺序学习，不要跳跃
- **记录学习**：在 `NOTES.md` 中记录学习心得
- **提问交流**：遇到问题随时向AI教师提问

### 学习记录
- 每次学习后，在 `docs/learning/records/` 目录下创建学习记录
- 记录格式：`0001-<学习主题>.md`
- 记录内容：学到了什么、为什么重要、下一步计划
