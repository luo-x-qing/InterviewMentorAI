# 学习笔记

## RAG技术学习笔记

### 2026年7月16日

**学习内容：**
- RAG核心概念
- 文档分块策略
- 向量嵌入技术

**学习心得：**
1. RAG的核心思想是"先检索，后生成"，通过检索外部知识库来增强LLM的生成能力
2. 文档分块是RAG系统效果的关键因素，需要根据应用场景选择合适的分块策略
3. 向量嵌入技术将文本转换为向量空间中的点，语义相似的文本在向量空间中距离更近

**遇到的问题：**
- 如何选择合适的嵌入模型？
- 如何平衡检索精度和性能？

## 项目集成笔记

### InterviewMentorAI项目RAG集成方案

**项目现状分析：**
- 纯LLM推理模式，没有外部知识库支持
- 双后端架构（Java + Python）
- 需要保持现有架构不变，逐步添加RAG功能

**集成方案：**
1. 在Python AI后端添加RAG服务
2. 构建面试相关的知识库
3. 实现混合检索策略
4. 增强现有的LLM服务

**技术选型：**
- 嵌入模型：BAAI/bge-large-zh-v1.5
- 向量数据库：ChromaDB
- 检索策略：混合检索（BM25 + 向量检索）

**实施步骤：**
1. 环境准备：添加Python依赖，创建项目结构
2. 核心组件：实现RAG服务、RAG API、增强LLM服务
3. 知识库构建：创建知识库目录，添加示例知识
4. 测试评估：单元测试、集成测试、性能测试

**风险和挑战：**
- 需要在不破坏现有架构的前提下添加RAG功能
- 需要考虑中文面试场景的特殊需求
- 需要支持实时性和准确性的平衡

**下一步行动：**
1. 开始原型开发，构建基础RAG功能
2. 集成到现有的Python AI后端
3. 进行初步测试和评估
4. 根据测试结果优化和迭代
