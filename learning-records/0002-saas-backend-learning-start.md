# Java SaaS 多租户业务后端学习起点

用户希望学习 SaaS 多租户业务后端架构，并理解 InterviewMentorAI 项目的 Java 后端设计逻辑。这是一个系统性学习目标，需要从架构概念到具体实现逐步掌握。

## 学习背景

当前项目已完成 Java 后端的 Phase 1-3 重建：
- Spring Boot 3.2.5 + Java 17
- 多租户 SaaS 架构（平台 schema + 租户 schema）
- JWT 认证 + RBAC 三层权限
- 8 个业务模块（34 个 API）
- 异步调用 Python AI 后端
- STOMP WebSocket 实时推送

## 学习目标

1. 理解 SaaS 多租户架构的核心概念和设计模式
2. 掌握 Spring Boot 3 + Java 17 的基础设施搭建
3. 理解 JWT 认证和 RBAC 权限体系的工作原理
4. 掌握多租户数据隔离的实现方式
5. 理解 MyBatis-Plus ORM 和数据库设计
6. 掌握异步调用和 WebSocket 推送机制
7. 理解 RESTful API 设计和 Controller 层实现
8. 能够独立实现业务逻辑模块
9. 能够串联整体架构，进行实战开发

## 学习路径

### 第一阶段：架构概念（课程 1-2）
- SaaS 多租户架构核心概念
- Spring Boot 3 + Java 17 基础设施

### 第二阶段：安全与权限（课程 3-4）
- JWT 认证与 RBAC 权限体系
- 多租户数据隔离设计

### 第三阶段：数据与持久化（课程 5）
- MyBatis-Plus 与数据库设计

### 第四阶段：异步与实时（课程 6）
- 异步调用与 WebSocket 推送

### 第五阶段：API 与业务（课程 7-8）
- RESTful API 设计与 Controller 层
- 业务逻辑实现（核心模块串联）

### 第六阶段：总结与实战（课程 9）
- 整体架构回顾与实战练习
